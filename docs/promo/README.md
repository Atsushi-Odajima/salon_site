## 制作見本の紹介文（215文字）

美容室向けホームページの制作見本です。メニューを選ぶだけで、税込の合計金額と所要時間がその場で分かる「料金シミュレーター」を搭載。カット＋カラーなどのセットと追加メニューを選ぶ方式なので、料金の誤解が起きにくくなります。スタッフ紹介では得意なスタイルや接客で大切にしていることを伝え、気になる担当者をそのまま指名して予約へ。空いている時間だけが表示されるため、スマホでも迷わず予約まで進めます。お店側の予約管理画面も体験できます。

## オーナー様向けの特徴（3項目）

1. **料金と時間が、お客様にひと目で伝わる**
   基本メニュー＋オプションを選ぶと、税込合計と所要時間をすぐ表示。料金表・予約・管理画面で同じ料金データを使うので、表示のずれが起きません。ロング料金や指名料のルールもはっきり示せます。
2. **スタッフの個性が伝わり、指名につながる**
   得意なスタイル、カウンセリングで大切にしていること、担当できるメニュー、指名料を一人ずつ紹介。「この人で予約する」から、選んだメニューを引き継いだまま予約できます。
3. **予約の受付から管理まで、ひとつの流れで**
   勤務時間・休憩・個室の空きを見て、予約できる時間だけを表示。お店側はスタッフ別のタイムラインで1日の予約を確認し、来店済み・キャンセルを切り替えられます（見本はブラウザ内保存。本番運用には認証・通知などの追加対応が必要です）。
